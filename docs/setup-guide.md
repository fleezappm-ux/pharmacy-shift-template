# 導入手順書（はじめての店舗向け）

所要時間のめやす：60〜90分。パソコンで進めます。**1つ終わるごとに ☐ にチェック**を入れてください。
かならず「自分の店専用」の新しいGAS・Notionを使います（別の店のものを共用しません）。

> **先に読んでください**
> - ブラウザの自動翻訳がONだと、GitHubなどの画面が日本語に変わり、この手順書のボタン名（`New repository secret` など）と合わなくなります。迷ったら、翻訳をOFFにするか、ボタンの位置で探してください。
> - 接続キー（`SHIFT_API_KEY`）は、**10文字以上で、英字と数字をまぜた値**にしてください。弱い値だと自己診断（2-5）で `NG` になります。
> - パスワードや接続キーは、ほかの人に見える場所（掲示板・GitHub・チャット）に貼らないでください。

## 全体の流れ

1. Notionにデータの入れ物を作る（約15分）
2. GASで「サーバー」を作る（約30分）
3. 公開サイトをつなぐ（約15分）
4. 自己診断→最初のログイン（約10分）
5. 従業員に配る

## 1. Notionの準備

- ☐ 1-1. [Notionの空テンプレート](https://app.notion.com/p/3e693d1ba8d8811abd62cbb9608f2fbe?pvs=204) を、自分のNotionに**複製**する
- ☐ 1-2. 複製したページの中に、データベースが3つあることを確認（シフト管理DB／シフト希望届／店舗設定DB）
- ☐ 1-3. Notionの「インテグレーション」画面で、新しいインテグレーションを作り、**シークレット**（長い文字列）をコピーして控える
- ☐ 1-4. 複製した3つのDBそれぞれで、右上「…」→「接続」から、そのインテグレーションを追加する（**3つとも**）
- ☐ 1-5. 3つのDBの**ID**（32文字）を控える。DBを開いたときのURLの、`notion.so/` のあとの32文字です

## 2. GAS（サーバー）の準備

- ☐ 2-1. [Google Apps Script](https://script.google.com) で「新しいプロジェクト」を作る
- ☐ 2-2. このリポジトリの `gas/Code.gs` の中身を**すべてコピー**して、エディタの `Code.gs` に貼り付け、保存
- ☐ 2-3. 左の歯車「プロジェクトの設定」→「スクリプト プロパティ」に、下の表を入れる

| キー | 入れるもの |
| --- | --- |
| `NOTION_API_KEY` | 1-3 のシークレット |
| `NOTION_SHIFT_DATABASE_ID` | シフト管理DBのID |
| `NOTION_SHIFT_REQUEST_DATABASE_ID` | シフト希望届のID |
| `NOTION_STORE_DATABASE_ID` | 店舗設定DBのID |
| `STORE_ID` | 店ごとの名前。例 `STORE-AOI-01` |
| `SHIFT_API_KEY` | **管理者用の接続キー**。長いランダムな文字列（10文字以上、英字と数字をまぜる）。自分で決めて控える |
| `SHIFT_ADMIN_LOGIN_ID` | 管理者のログインID |
| `SHIFT_ADMIN_SETUP_PASSWORD` | 管理者のパスワード |
| `SHIFT_EMPLOYEE_LOGIN_ID` | 従業員みんなで使うログインID |
| `SHIFT_EMPLOYEE_SETUP_PASSWORD` | 従業員みんなで使うパスワード |
| `SHIFT_INITIAL_OPERATOR_NAME` | あなた（最初の管理者）の名前 |

- ☐ 2-4. エディタ上部の関数選択で、次の3つを**1つずつ選んで「実行」**する（初回は権限の確認が出ます。自分のアカウントで許可）
  1. `configureShiftAdmin`
  2. `configureShiftEmployeeLogin`
  3. `initializeShiftOperator`

  （実行すると、パスワードは暗号化され、元の入力欄は自動で消えます）
- ☐ 2-5. 関数 **`checkShiftSetup`** を実行する → 下の「実行ログ」に `【すべてOK】` と出ればOK。`NG` の行があれば、その行の指示どおり直して、もう一度実行
- ☐ 2-6. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」。実行ユーザー「自分」、アクセスできるユーザー「全員」でデプロイ
  初回は「アクセスを承認」が出ます。**自分のアカウント**を選び、「詳細」→「（プロジェクト名）に移動」→「許可」の順に進めます（「このアプリは確認されていません」と出ますが、自分で作ったものなので大丈夫です）。
- ☐ 2-7. 表示される**ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピーして控える

## 3. 公開サイトをつなぐ

- ☐ 3-1. このリポジトリを自分のGitHubに**複製（Fork）**する。複製したら、Actions タブを開き、「ワークフローを有効にする（I understand my workflows, go ahead and enable them）」を押す（押さないと、自動公開も見張り役も動きません）。リポジトリ名は自由に変えて大丈夫です
- ☐ 3-2. 複製したリポジトリの Settings → Secrets and variables → Actions → New repository secret
  名前 `VITE_SHIFT_GAS_URL`、値は 2-7 のURL
- ☐ 3-3. Settings → Pages → Source を「GitHub Actions」にする
- ☐ 3-4. Actions タブで「Deploy shift tool to GitHub Pages」を実行（Run workflow）。緑のチェックが付けば公開完了
- ☐ 3-5. 公開されたURL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）を開く

## 4. 最初のログインと初期設定

- ☐ 4-1. 公開サイトを開き、管理者ID・パスワードでログイン、自分の名前を選ぶ。**はじめてのときは、自分のPIN（4〜6桁の数字）を決めます**（2回入れます。忘れないよう控えてください）
- ☐ 4-2. 画面上の黄色い案内から、**接続キー**（2-3 の `SHIFT_API_KEY`）を入れて「保存して接続を確認」。✓が出ればOK（1端末につき1回だけ）
- ☐ 4-3. 設定 → 従業員マスタで、自分の名前を直し、従業員を登録する
- ☐ 4-4. 設定 → 店舗マスタで、店舗名と集計期間（月の区切り）を決める
- ☐ 4-5. 設定 → シフトマスタ → 勤務時間設定で、早番・遅番などを登録する
- ☐ 4-6. 試しにシフトを1日入れて、「保存済み」になり、Notionのシフト管理DBに行が増えることを確認する

## 5. 従業員に配る

- ☐ 5-1. 公開サイトのURLと、**従業員共通のID・パスワード**を伝える（LINEなどで。掲示板やGitHubには書かない）。あわせて「**最初のログインで、自分のPIN（4〜6桁の数字）を決めてください**」と伝える。PINは本人だけが知る番号で、ほかの従業員のマイページや有給を見られなくするためのものです
- ☐ 5-1b. 従業員がPINを忘れたら、設定 → 従業員マスタ →「PIN（暗証番号）のリセット」で、その人の「PINをリセット」を押す。本人は次のログインで決め直します
- ☐ 5-2. スマホは「ホーム画面に追加」を案内する（ホームのシフトのアイコンに方法が出ます）
- ☐ 5-3. 使い方は、アプリ内の「使い方」と、Notionの説明書を見てもらう

## 見張り役（自動チェック）について

- 変更のたびに、型チェック・テスト・ビルドが自動で走ります（`CI`）。
- 6時間ごとに、公開サイトとGASが生きているかを自動で確認し、**止まっていたらGitHubからメールが届きます**（`Health check`）。メールはGitHubの通知設定がONなら届きます。
- 画面でエラーが起きると、自動で記録されます。管理者は 設定 → その他設定 の「エラー記録」で見られます。

## うまくいかないとき

| 症状 | 確認すること |
| --- | --- |
| `checkShiftSetup` に NG が出る | その行の指示どおりに直す。Notionにつながらないときは、1-4 のインテグレーション追加を再確認 |
| ログインできない | 2-3 のID・パスワードの綴り。`configureShiftAdmin` などを実行したか。「PINが違います」なら、本人に確認し、忘れていれば管理者がPINをリセット |
| 画面が「通信できません」 | 3-2 のURLが正しいか。2-6 のアクセス権が「全員」か |
| GASを直したのに反映されない | デプロイを「新バージョン」で更新したか（URLは変わりません） |
| 公開サイトが古い | 画面の更新ボタンを押す。Actionsが緑か確認 |

## 付録：データ初期化を使う場合

初期化は誤接続防止のため、標準では上記テンプレートの3DBだけが対象です。自分で複製したDBで使うときは、GASのスクリプトプロパティ `SHIFT_RESET_ALLOWED_DB_IDS` に、次の形で3つのIDを設定します（`NOTION_*_DATABASE_ID` と3件すべて一致しないと実行できません）。

```json
{"NOTION_SHIFT_DATABASE_ID":"店舗のシフトDB ID","NOTION_SHIFT_REQUEST_DATABASE_ID":"店舗の希望届DB ID","NOTION_STORE_DATABASE_ID":"店舗の店舗設定DB ID"}
```

この操作は対象DBのページをアーカイブします。ID を確認してから実行してください。
